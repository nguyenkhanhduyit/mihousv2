- Đối chiếu `pageadmin.rar` (HTML/CSS/JS quản trị) với các template được nhúng ở `src/cms/sourceAdminTemplates.json`; tham khảo `_home.html` cho cấu trúc trang chủ.

- Thay đổi thực hiện trong **bản sao** dự án. Không có quyền sửa hệ thống production của người dùng.
- Trạng thái `PATCHED` = đã thay đổi source, **không** tương đương đã kiểm thử thực tế trên trình duyệt. `PASS` chỉ dùng cho bài test cụ thể được chạy.

## Các giới hạn chặn nghiệm thu 100%

1. `npm ci` / `npm run build` **BLOCKED**: môi trường kiểm tra không truy cập được `registry.npmjs.org` (`EAI_AGAIN`); không có bản `node_modules` có thể dùng cho Linux. Chưa có build sạch bằng Vite.
2. Browser E2E/Visual Regression **NOT TESTED**: không có ứng dụng React được build thành công để đối chiếu screenshot cùng viewport với Admin, trang chủ và trang con. Các style và chuyển động cần test thực tế.
3. Cloudinary **BLOCKED**: không có thông tin tài khoản thật. Bộ API test sử dụng mock Cloudinary, tuyệt đối không upload/xóa tài nguyên thật.
4. **Vercel không thể vận hành backend hiện tại nếu chỉ deploy mã nguồn này**: `vercel.json` chỉ rewrite đường dẫn về `index.html`, trong khi `/api/admin/*` là Node HTTP server riêng với sessions in-memory và `server/data/content.json` cần đĩa ghi bền vững. Cần triển khai Node trên host có storage bền vững, hoặc thiết kế lại API serverless + database/KV và session bền vững trước khi Vercel production PASS.
5. Các file `SVN-Gilroy` và một số icon-font cần thiết được tham chiếu bởi CSS nhưng **không có trong bộ file trích xuất**. SVG fallback không thay thế được toàn bộ font chữ nguyên bản; cần bổ sung tài nguyên có quyền sử dụng để khớp 100%.
6. Thư viện Cloudinary thực được giới hạn ở `mi-house/`. Tài nguyên hiện trên Cloudinary nhưng chưa ghi vào CMS có thể Copy URL; nút xóa/thay bị khóa nhằm tránh phá dữ liệu ngoài phạm vi CMS. File có trong CMS nhưng không thuộc prefix sẽ xuất hiện ở chế độ fallback khi Cloudinary chưa cấu hình.
7. Chưa xác minh lỗi Console, Network, độ giống pixel, responsive và hiệu ứng trên thiết bị thực.

## Vận hành và tránh mất dữ liệu

- `.env` và khóa API không được đóng gói. Dùng `.env.example` làm mẫu rồi tự tạo `.env` trên host.
- `server/data/content.json` giữ dữ liệu hiện có từ bản gốc, không dùng dữ liệu mẫu từ Admin RAR để ghi đè.
- Xác nhận một bản sao lưu trước khi chạy migration, đăng nhập hoặc sửa/xóa trực tiếp trên production.
- Nếu triển khai Node lâu dài, cấu hình `CMS_DB_PATH` tới volume bền vững. Không lưu password/secret vào client.
